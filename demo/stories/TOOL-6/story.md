# TOOL-6: Category tree for the mobile app

The mobile app shows the shop's categories as a tree, the same one the web shop shows in its filter. It reads them from the public catalogue API.

API reference: [Toolshop API reference|https://jira.example.com/confluence/pages/viewpage.action?pageId=880002]
The complete OpenAPI file is on the API portal: https://api.practicesoftwaretesting.com/api/documentation
