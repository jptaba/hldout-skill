Two clarifications from refinement, please treat these as part of the story:

1. The password minimum in the description is out of date. We agreed to keep the existing rule so current customers are not locked out: a password must be **7 to 100 characters**. A 7-character password is valid, a 6-character one is rejected.
2. E-mail addresses are not case sensitive. `Jane.Doe@Example.com` and `jane.doe@example.com` are the same address: signing up with a different capitalisation of an existing address is a duplicate (AC-5), and signing in works with any capitalisation of the registered address.
